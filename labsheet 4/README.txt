C++ Lab Sheet 04 — BCA I Semester

This folder contains 30 separate C++ source files, one for each question in Lab Sheet 04.

How to compile and run in VS Code:
1. Open the "Lab Sheet 04" folder in VS Code.
2. Open a .cpp file.
3. Open Terminal > New Terminal.
4. Compile the current file, for example:
   g++ Q01_Positive_Negative.cpp -o Q01
5. Run it in PowerShell:
   .\Q01.exe

Repeat with the matching filename/output name for each question.
Note: Q06 uses example grade bands (A: 90+, B: 80-89, C: 70-79, D: 60-69, E: 40-59, F: below 40).
Change those bands if your instructor has specified a different grading scheme.
Q09 maps 1 to Monday and 7 to Sunday.
